# 우수꾸(가제)

**우리 수영장 꾸미자.** 워치로 잰 그날의 수영 기록이 캐릭터 아이템이 되고, 같은 수영장 사람들과 함께 리프를 키우는 수영 앱의 디자인 시안이에요.

피그마 원본(`우수꾸 시안` 페이지)의 오토레이아웃 · 텍스트 스타일 · 컬러 값을 그대로 HTML/CSS로 옮겨서, 실제로 눌러볼 수 있는 앱으로 만들었어요. 빌드 과정은 없어요.

## 실행

- **앱**: `index.html` — 스플래시 → 로그인 → 캐릭터 선택 → 수영장 선택 → 메인 탭
- **디자인 시안**: `about/index.html` — 화면 13개를 플로우별로 모아 본 갤러리

데모 데이터로 동작하고, 고른 캐릭터와 꾸민 아이템은 브라우저(localStorage)에 저장돼요. 전체 메뉴 > 데모 처음부터 다시로 초기화할 수 있어요.

## 앱에서 되는 것

- 캐릭터(토끼 · 햄스터 · 곰 · 고양이 · 양)와 털 색, 이름 고르기 → 모든 화면에 반영
- 위치 기반 수영장 고르기 → 우리 수영장 · 마이에 반영
- 오늘의 상자 열기 → 해달 수경 획득
- 꾸미기: 수모 · 수경 착용(캐릭터에 바로 보임), 수영복 · 오리발 고르기, 따라오는 바다 친구 최대 3마리
- MY POOL: 위에서 / 옆에서(레인 왕복 루프) 보기, 아이템 놓기, 물방울 쪽지
- 바다 도감: 분류 필터, 친구 상세와 따라오게 하기
- 전체 메뉴 · 마이 · 공지사항(필터, 펼쳐 읽기, 읽음 표시)

## 핵심 규칙

- **보상**: 영법 = 아이템 테마(자유형 물고기 · 평영 바다거북 · 배영 해달 · 접영 고래), 거리 = 상자 등급, 효율 향상 = 반짝이 등급
- **꾸준함**: 매일이 아니라 주간 연속 기록
- **세계관**: 물이 무서운 육지 동물들이 수영을 배우는 중. 기록이 쌓이면 킥판 · 튜브를 졸업. 안내는 물개 코치
- **캐릭터**: 토끼 · 햄스터 · 곰 · 고양이 · 양. 볼살 튀어나온 얼굴, 바깥 선만, 젖어서 뻗친 털, 음파(숨 참기) 표정
