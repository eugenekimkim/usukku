# 우수꾸(가제) 디자인 시안

**우리 수영장 꾸미자.** 워치로 잰 그날의 수영 기록이 캐릭터 아이템이 되고, 같은 수영장 사람들과 함께 리프를 키우는 수영 앱의 디자인 시안이에요.

피그마 원본(`우수꾸 시안` 페이지)의 오토레이아웃 · 텍스트 스타일 · 컬러 값을 그대로 HTML/CSS로 옮겼어요. 이미지가 아니라 실제 레이아웃이라 글자 선택과 수정이 가능해요.

## 보는 방법

`index.html`을 브라우저로 열면 돼요. 빌드 과정은 없어요.

- 화면을 누르면 크게 보기, ← → 키로 넘기기
- 화면 아래 탭바를 누르면 해당 화면으로 이동
- `04-2 MY POOL · 옆에서`는 캐릭터가 레인을 왕복하는 루프가 재생돼요

## 구조

| 파일 | 내용 |
| --- | --- |
| `index.html` | 갤러리 페이지 (플로우별 섹션) |
| `css/tokens.css` | 디자인 토큰: 컬러, 텍스트 스타일(Display~Label), 오토레이아웃 규칙 |
| `fonts/suite.css` | SUITE Regular · Medium · Bold · ExtraBold (SIL OFL 1.1, `fonts/SUITE-LICENSE.txt`) |
| `js/screens.js` | 피그마 오토레이아웃을 옮긴 빌더(`al` · `txt` · `art`)와 화면 13개 |
| `js/art.js` | 동물 친구 · 바다 친구 · 물개 코치 SVG 생성기 |
| `js/props.js` | 아이콘, 소품, 수영장 장면 SVG |
| `js/app.js` | 갤러리 렌더링, 크게 보기, 캐릭터 시트, 컬러 · 텍스트 스타일 표 |

## 핵심 규칙

- **보상**: 영법 = 아이템 테마(자유형 물고기 · 평영 바다거북 · 배영 해달 · 접영 고래), 거리 = 상자 등급, 효율 향상 = 반짝이 등급
- **꾸준함**: 매일이 아니라 주간 연속 기록
- **세계관**: 물이 무서운 육지 동물들이 수영을 배우는 중. 기록이 쌓이면 킥판 · 튜브를 졸업. 안내는 물개 코치
- **캐릭터**: 토끼 · 햄스터 · 곰 · 고양이 · 양. 볼살 튀어나온 얼굴, 바깥 선만, 젖어서 뻗친 털, 음파(숨 참기) 표정
